🏛️ Executive Summary & Ecosystem Overview

The Multi-School Management SaaS Platform is a multi-tenant software solution engineered to allow platform administrators to provision, manage, and scale independent educational institutions under a single unified cloud infrastructure.

Each onboarded school operates within an isolated logical tenant boundary while leveraging shared backend services, automated subscription billing, and cloud-synced mobile and web applications.

🏫 School Admin Panel

Academic calendars, fee collection structures, staff & student admissions, timetable generation, and SMS alerts.

📱 Student & Parent App

Flutter cross-platform app with multi-child switching, attendance tracking, online fees, and exam report cards.

👨‍🏫 Staff & Teacher App

Flutter app for instant attendance recording, homework assignments, grading, timetable schedule, and leave approvals.

🔐 User Roles & Permission Matrix (RBAC)

The platform enforces strict role-based access control across web consoles and mobile apps:

User Role Access Level Credentials Format Key Privileges & Scope
Principal / School Admin Tenant School PRIN-<CODE>-01 + Password Configure school branding, sessions, classes, teachers, student rosters, fee structures, and notices.
Teacher / Staff Assigned Classes TCH-<CODE>-01 + Password Record student attendance, post homework/assignments, grade submissions, manage lesson plans, apply for leave.
Student / Parent Personal & Family Record ADM-<CODE>-001 + Password Multi-child profile switching, view subjects, announcements, timetables, download ID cards, submit homework.

📱 Detailed Functional Modules

👨‍👩‍👧 Student & Parent Mobile Application

  • Multi-Profile Guardian Switcher: Toggle smoothly between multiple children in the school.
  • Academic Hub: Subject-wise syllabus, daily diary notes, and downloadable student ID cards.
  • Homework Engine: Task descriptions, attachments, and online submission portals.
  • Communication & Media: Instant school notices, holiday calendar, bus GPS route tracking.

👨‍🏫 Teacher & Staff Mobile Application

  • 1-Tap Quick Attendance: Bulk attendance marking with instant save.
  • Emergency Directory: Class rosters, roll numbers, and one-tap emergency calling.
  • Grading & Workflow Automation: Assignment evaluation and exam mark entry.
  • Leave Applications: Submit digital leave requests to principal.

🚀 Step-by-Step Implementation & Deployment Guide

1

Step 1: Backend Setup & API Linkage

Deploy backend on port 8088. Update Flutter constants (mobile_app/lib/core/constants.dart):

const String baseUrl = "http://localhost:8088/api";
2

Step 2: Firebase Cloud Messaging Configuration

Configured in mobile_app/android/app/google-services.json for push notifications.

3

Step 3: Application Rebranding

Configured in mobile_app/android/app/src/main/AndroidManifest.xml with label EduSaaS Mobile.

4

Step 4: Custom Asset Replacement

Launcher icons in mobile_app/android/app/src/main/res/mipmap-*.

5

Step 5: Compilation & Release

Execute release compilation using DEPLOY_FLUTTER_APP.bat.
